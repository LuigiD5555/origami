# Gatekeeper quickstart

- Your canonical PR: Gatekeeper classifies `OWNER`; run normal Origami CI/evidence. Explicit owner override remains a deliberate promotion decision.
- Someone else's PR/fork: Gatekeeper classifies `EXTERNAL`; normal CI/evidence plus an `APPROVED` review from `LuigiD5555` is required.
