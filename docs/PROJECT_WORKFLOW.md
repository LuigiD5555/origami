# Origami project workflow

1. Change Origami on a branch and open a PR.
2. Gatekeeper classifies OWNER or EXTERNAL.
3. Run Origami CI/evidence; external work additionally requires owner approval.
4. Promote Origami without changing scientific PASS/FAIL claims to satisfy promotion.
5. In Tonal, update the exact Origami pin and run full-stack verification/snapshot before distributing the new composition.

Shared Git/repository and provenance skills belong to Tonal. Origami representation, state, observation and experiment semantics remain owned here.
