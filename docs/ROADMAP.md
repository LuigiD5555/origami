# Origami roadmap

This roadmap separates **core Origami language/runtime work**, **Virtual Memory**, **perceptual promotion**, and the **OHF carrier/laboratory track**.

## Core Origami 6.x

Current priorities:

1. keep coherent-state, Fold/Unfold, addressability and perceptual-channel contracts semantically stable;
2. continue executable reference support for interference, depth and Temporal Latent Image operations without conflating contract definition with implementation;
3. preserve explicit unsupported-operation behavior;
4. expose versioned contracts usable by Tlaloc or any other consumer.

## Virtual Memory R0

Alpha.4 implements the deterministic reference architecture. Next experiments should focus on scale rather than adding unrelated features:

1. build richer ingestion that emits labels/abstracts/summaries/details/evidence/exact refs plus semantic/dependency/provenance graphs;
2. validate graph-signature federation over increasing carrier counts;
3. measure Useful Context Efficiency and Knowledge Scale Degradation with the active context fixed near 4000 token-equivalent;
4. add query classes beyond the current causal/evidence/contradiction/exact heuristics without allowing hidden exact-payload scans;
5. improve cost/utility ranking from experimental measurements;
6. test working-set reuse across multi-turn conversations;
7. keep `ContextPacket` model neutral.

A specialized Origami LLM is intentionally **after** these tasks. It should optimize use of the same public memory interface, not become a hidden requirement of the representation.

## Visual Memory / Perception Lab

The macro/meso/micro projection is implemented but not Native-promoted. Required work:

- carrier/root selection;
- cluster selection;
- macro -> meso -> micro descent;
- typed edge following;
- random address reopening;
- irrelevant-cluster rejection;
- resize/degradation robustness;
- carrier-local symbol permutation;
- pair/higher-order family interaction tests;
- cross-model held-out evidence.

Only families/compositions that pass the declared scope may contribute to SAFE perceptual capacity. F01–F42 remain generator-tree candidates rather than a Cartesian product.

## OHF research track

Continue the executable R3.10-LAB workbench as the main carrier research line:

- DVR / PSS evidence and orthogonality gates;
- Glyph Calculus / SAFE_MICRO_ISA / Context SIMD;
- Macro-Gestalt experiments;
- representation tournament / grammar / transform / Dependency Folding;
- Virtual Memory carrier materialization;
- conservative Native/Hybrid evaluation;
- exact historical R3.10 SDK recovery if authentic bytes become available.

OHF-specific `<=500 KB`, `FALSE_EXACT=0` and Native-boundary invariants remain track requirements unless explicitly revised by an OHF change record.

## Scaling experiment

The decisive memory experiment is:

```text
1 carrier -> 10 -> 100 -> 1,000 -> ...
active model-facing context held constant
```

Track answer/evidence accuracy, carrier/cluster routing, touched/unfolded nodes, graph hops, exposed/irrelevant tokens, latency, Useful Context Efficiency, Knowledge Scale Degradation and `FalseExact`.

## Cross-project integration

Tlaloc may search/distill better receiver behavior or later help train a specialized consumer. Origami remains independently versioned and authoritative for representation, memory, addresses, carrier semantics and exactness rules.

## Promotion rule

Do not promote a perceptual dimension, compound, operation or profile from mathematical plausibility or deterministic transport alone. Promotion requires deterministic validity where applicable, controlled mutation, perception/evaluation evidence and regression coverage for the declared scope.
