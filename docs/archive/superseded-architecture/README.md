# Superseded Origami architecture

This directory preserves architecture material superseded by Architecture R2.

Historical documents may describe Tonal only as an optional composition layer. That statement is historical. Origami remains independently testable, but current ecosystem authority defines Tonal as the complete heterogeneous runtime/research system and Origami as an optional representation/carrier/memory subsystem within that ecosystem.

Current authority begins with root `CLAUDE.md`, `docs/ROLE_IN_TONAL.md` and current state/architecture documents.
