This directory preserves the detailed OHF/R3.10-LAB documents that previously occupied Origami's root/current documentation slots.

They remain active research evidence for the **OHF track**, but they are no longer authoritative descriptions of the complete Origami project.

- `R310_LAB_ARCHITECTURE.md` — detailed OHF sender/receiver, perception/resolution/execution/verification pipeline.
- `R310_LAB_CURRENT_STATE.md` — detailed R3.10-LAB implementation and blocker state as integrated on 2026-08-27.
- `R310_LAB_DEVELOPMENT.md` — detailed OHF experimental/change workflow.
- `R310_LAB_INSTALLATION_LIFECYCLE.md` — full reversible installer semantics for `ohf-lab` and `ohf-glyphcalc`.
- `R310_LAB_ROADMAP.md` — detailed OHF research sequence.

For the current project-wide hierarchy, use the root `README.md`, `PROJECT_BOUNDARY.md`, `docs/CURRENT_STATE.md`, `docs/ARCHITECTURE.md` and `docs/ROADMAP.md`.
