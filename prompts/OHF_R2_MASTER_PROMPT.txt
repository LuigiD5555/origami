## BOOT

## R2 binary decoding
For the supplied carrier the BOOT header defines:
- binary cells, black=1 and white=0
- row-major order
- MSB-first within every byte
- sample the center of each cell
- envelope:
  magic[8] | version:u16 big-endian | len:u32 big-endian |
  crc32:u32 big-endian | sha256[32] | zip[len]

Use the geometry written in BOOT rather than assuming coordinates.

If Python/PIL is available, decode directly from the original image:

4. Read the first 50 bytes from cells.
5. Require magic == b"OHFR2ZIP".
6. Parse version, payload length, CRC32 and SHA256.
7. Read exactly 50 + payload_length bytes.

Reference algorithm:

    from PIL import Image
    import struct, hashlib, zlib, zipfile, io

    img = Image.open(IMAGE_PATH).convert("L")
    # Read x0,y0,cell,cols from BOOT. For this carrier BOOT states them explicitly.
    x0, y0, cell, cols = GRID_X, GRID_Y, CELL, COLS

    def read_bytes(n):
        out = bytearray()
        for byte_i in range(n):
            v = 0
            for j in range(8):
                bit_i = byte_i*8 + j
                r, c = divmod(bit_i, cols)
                px = img.getpixel((x0 + c*cell + cell//2,
                                   y0 + r*cell + cell//2))
                v = (v << 1) | (1 if px < 128 else 0)
            out.append(v)
        return bytes(out)

    h = read_bytes(50)
    assert h[:8] == b"OHFR2ZIP"
    version, n, expected_crc = struct.unpack(">HII", h[8:18])
    expected_sha = h[18:50]
    blob = read_bytes(50+n)[50:]
    assert (zlib.crc32(blob) & 0xffffffff) == expected_crc
    assert hashlib.sha256(blob).digest() == expected_sha
